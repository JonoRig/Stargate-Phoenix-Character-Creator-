# Stargate SG-1 RPG — Phoenix Site Character Creator

A fan-made, browser-based character creator and dossier generator for the Stargate SG-1 roleplaying game. This is an unofficial hobby project, not an official game product or a substitute for the rulebook.

## Use

Download the HTML file from this repository and open it in a modern browser. No installation is required. Use the tabs to build a character, choose feats and equipment, track missions, and manage rosters. You can print or save a dossier as a PDF using your browser's print dialog.

Roster data can be saved in the browser, exported to JSON, and imported again. Where the browser supports folder access, you can also choose a folder for the roster JSON file. **Keep an exported backup:** browser-stored data may be lost if you clear site data or change browsers or devices.

This is a fan tool; please check character options and rules interpretations against the game materials you use at your table.
